# Harshit Kumar — Portfolio

Award-winning caliber portfolio website engineered with real-time 3D WebGL background choreography, Web Audio API procedural sound synthesis, scroll-driven chapter narratives, and live interactive benchmarks.



## Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **3D Graphics:** Three.js (Geodesic icosahedron wireframe + interactive particle constellation with inertia damping)
- **Styling:** Tailwind CSS v4 + Custom Cyberpunk / Editorial Design Tokens
- **Sound Engine:** Procedural Web Audio API (zero external audio file latency)
- **Icons:** Lucide React + Custom brand SVGs

## Featured Systems
1. **Lexis AI** — Modular content orchestration engine with 8-stage stateful LangGraph pipeline, ChromaDB vector store, and C++ translation engine. ([Live App](https://lex-is-ai.vercel.app/app/))
2. **TruthShield Sentinel Core** — High-throughput security API for real-time visual forensics and text scam identification. ([Live App](https://truthshield-nu.vercel.app/))
3. **Basera & Homie** — AI-powered housing platform with virtual LLM landlords (<350ms TTFT) and real-time geospatial search (<8ms ray-casting). ([Live App](https://homie-two-pi.vercel.app/))
